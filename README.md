# مخطط السفر

إنشاء رحلات متعددة مع الوجهة والتواريخ والميزانية، برنامج يومي بالأنشطة، تتبع المصاريف حسب الفئة مع المتبقي من الميزانية، قائمة تجهيز، وملاحظات. كل البيانات محفوظة في localStorage. لا توجد خدمة خرائط متصلة، لذلك يستخدم التطبيق عرضا قائما على القوائم بدلا من خريطة حية.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## اللغات

عربي (RTL) وإنجليزي (LTR) مع مبدّل لغة ظاهر، والتفضيل محفوظ في localStorage. ملفات الترجمة في `locales/en/common.json` و`locales/ar/common.json`.

## التقنية

React + TypeScript + Vite + Tailwind CSS. أيقونات Phosphor.
